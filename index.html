03 // EXPLICIT CONTROL

Your Mac is not a hidden tool.

fx and macOS Control are separate switches. Enable the agent without handing it your Desktop, then grant Mac control only for the turns that truly need it.

  • fx AgentWorkspace tools and managed execution
  • macOS ControlOff by default, visible when enabled
  • Browser modeIsolated and enabled per session
  • Memory scopePrivate star or shared constellation
